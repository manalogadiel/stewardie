# Map and navigation pilot setup

The Flutter app now uses a shared `flutter_map` tile component for the Space map, fixed place picker, and pinned photo viewer. The Space map opens privately and requests a current location fix; the **Start sharing** action is still separate. A recent device fix can center the map while GPS resolves. Panning stops automatic recentering until **Recenter** is pressed. Photo maps use only the saved pin and never request the viewer's location.

## MapTiler free development key

1. Create a MapTiler Cloud Free account and a public API key in its dashboard. Restrict the key to this app's use where MapTiler supports it. Do not activate billing.
2. Plain `flutter run` now includes the user's public pilot MapTiler key as the default. No launch flag or local key file is required. `--dart-define=MAPTILER_KEY=...` still overrides it; an explicitly empty value selects the Streets fallback. This client tile key is bundled in the app, unlike server credentials. Do not activate billing.
3. Satellite is the default; the single **Layers** button opens Satellite and Streets choices. With no key, the component uses OpenStreetMap Streets tiles and explains why satellite is unavailable. Tile errors show a retry action and suggest Streets.
4. Check [MapTiler's current Free allowance and terms](https://www.maptiler.com/cloud/pricing/) before using a key and before public/commercial release. The free plan is for the private development pilot in this rollout. Review a suitable licensed plan before commercial launch. MapTiler requires visible [map attribution](https://docs.maptiler.com/guides/map-design/attribution/add-attribution/), including its linked logo on Free. The shared map shows the official linked [PNG logo](https://www.maptiler.com/press/) and separate linked copyright credits when a key is configured. Check that the logo loads on a device before inviting testers.

The Space map, fixed pins, and photo viewer can be exercised locally without a MapTiler key using Streets. Native location permission, movement, background sharing, and map gestures still need physical-device checks on Android and iOS. The latest scheduled worker and Firestore rules/indexes were deployed to the existing free projects on September 29, 2026; see the [completion verification record](map-navigation-completion-verification.md) for test results and open device checks. Client task and ownership request cards stay available if the worker is delayed.
