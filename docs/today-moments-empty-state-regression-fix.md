# Today content and empty Moments header regression

Status: corrective implementation plan, September 30, 2026. This updates the diagnosis in [the earlier empty-space and tour plan](empty-space-and-tour-visual-plan.md); it does not authorize changing unrelated onboarding, backend, or map work. The supplied screenshot shows the **no-space Moments** screen (`Little moments`), while the report that Today is empty is a separate symptom. Code inspection is not a device reproduction.

Update: an in-progress local change now gives empty Moments a full-width `CustomScrollView`. That exposed a shared-scroll-state risk with Today. The current Today fix gives the two scroll views distinct keys, retains the Today hero during loading/errors, and guards against a stale selected-space ID. Device reproduction remains open.

## Review of the current Flutter code

- `OnlineHome._today` now sends the no-space branch to `_todayPage`, with a Today hero, an empty-state panel, and Create/Join actions. The earlier plan's statement that this branch still uses `_page([_hero(...)])` is no longer true. Do not reapply that old patch or replace the working Today hierarchy.
- When a space exists, `_today` still builds member filters, `OnlineTodayExtras` (mood/calendar), Help/Covered/Done counts, Pending/Done tabs, and task cards. Thus an entirely blank Today needs reproduction and a check of its space, stream, loading, and error state; the screenshot alone does not establish which of these failed.
- `OnlineHome._moments` still returns `_page([_hero('Little moments', ...), ...])` when `spaceId == null`. `_page` adds 20 logical pixels on each side and `topControlsClearance(context)` above its children. That directly explains the inset yellow card and white strip in the supplied Moments screenshot.
- The top controls are overlaid in `OnlineHome.build` and its body uses `SafeArea(top: false)`. The page can paint behind the status bar; the Moments no-space content layout currently prevents it. `Scaffold.extendBody` addresses the bottom, not this top inset.

## Corrective work

1. **Reproduce Today before changing it.** Record whether the account has zero spaces or a selected space, which dock tab is highlighted, and whether the space/member/task streams are waiting, errored, or loaded. Check Today immediately after sign-in, after dismissing the tour or Create/Join sheet, after switching tabs, and after creating/joining a space. If the visible page says `Little moments`, that is the Moments branch; inspect dock index and route state if Today is highlighted at the same time. Do not use Moments artwork as evidence that Today data was deleted.
2. **Restore visible Today content in each valid state.** No-space Today must show its full-width Today/date/mascot hero, the "Bring your people together" panel, and reachable Create/Join actions. With a space, preserve people filters, mood/calendar, counts, Pending/Done controls, and tasks. Give stream waiting and failure states a visible, appropriately placed indicator or retry message, rather than an apparently empty page. Keep cached data visible while refreshing when safe; do not turn loading or a temporary history request failure into a blank screen. Ensure `selected` and `_personId` cannot leave the page filtered to a member outside the newly selected space. Fix the actual reproduced cause without rebuilding the whole screen or replacing existing data.
3. **Make the no-space Moments hero full bleed.** Move the yellow surface out of `_page`'s horizontal/top padding. Use the same top-edge geometry as the Today hero: color from screen top behind map/selector/bell and the status bar, square top edge, rounded bottom corners, and top-control clearance *inside* the surface. The `Make a space first` panel starts below it with normal 20-pixel content margins. Prefer a shared, small hero/sliver component if it reduces duplication, but keep Today and Moments copy and existing interactions intact. Do not add a solid rectangular navigation bar.
4. **Check the other Moments states.** With a space, retain the existing Moments feed, add/upload flow, photos, and TV presentation. Do not use the no-space placeholder in a loading or temporary error state. Confirm changing spaces refreshes the correct space's photos and does not expose a previous space's content.

## Acceptance and minimal verification

- On an account with a space, Today retains every existing section and task interaction; Moments retains the existing photo feed and actions. Switching Today → Moments → Space → Today does not blank Today or mismatch the selected dock tab.
- Check a small and a larger phone, notch/status bar, 1.3× text, and the initial stream-loading/error states. The map, selector, bell, and dock remain tappable and legible. Tour and Create/Join sheets dismiss back to the correct tab.
- Run focused `flutter analyze` on touched files and only targeted widget tests for the no-space hero geometry and Today state/tab behavior. If the blank Today cannot be reproduced locally, report the exact states tested and leave the cause marked unconfirmed; do not claim a fix based only on the screenshot.
